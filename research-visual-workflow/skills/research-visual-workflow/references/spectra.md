# XRD、拉曼和 FTIR 图谱编辑

## 按输入决定能编辑什么

- **有原始数据或可编辑工程**：优先使用源数据。保留样品映射、列名、单位、扫描顺序与缺测。Origin 或仪器文件先用兼容工具导出表格。不同横轴网格用各自的横坐标画线或分面，勿为套用单横轴脚本而默认插值。不要把 SVG 或 PDF 称为可编辑 Origin 工程。
- **只有截图、PNG 或扁平 PDF**：可调整留白、图题、面板布局，或添加用户提供的标签。保留已有断线，不擦掉或重画曲线。定量重绘请索取源数据。用户明确要求数字化时，将提取的点单独存为近似数据，记录出处、坐标校准和误差限制，勿据此给出精确峰位或物相结论。

## 各图谱的检查项

| 类型 | 轴和曲线 | 可以添加的标注 |
| --- | --- | --- |
| XRD | 角度扫描通常为 `2θ (°)`。核对 X 轴是否实际为 θ、d 或 Q。Y 轴按原数据写 counts、counts/s 或已说明的相对强度。 | 只标已知或经来源核验的位置。标物相、晶面或卡片时记录来源及适用辐射波长。有参考峰列表时把参考棒与实测曲线区分开。 |
| Raman | 横轴为 `Raman shift (cm⁻¹)`。保留原始强度定义，激光波长等采集条件放图注或方法。 | 可标用户指定的峰位、已核验的峰归属或展示局部范围。重叠峰保留其原始形状。 |
| FTIR | 横轴为 `Wavenumber (cm⁻¹)`，脚本默认从高到低显示。核对 Y 轴是透过率（%T、比例 T）还是吸光度，并保持原量和原单位。 | 可标用户给出的波段或已核验归属。保留透过率谱的向下吸收带。 |

默认只改版式。平滑、基线扣除、归一化、峰分解、透过率与吸光度转换须由用户明确要求，另存派生数据并说明算法、参数和依据。叠谱的垂直偏移也要标出量值与原单位；偏移图的高度不能直接作为组间强度比较。保持缺测断线，包括仪器未扫描的范围；表中整个区间未记录时需根据已知扫描范围显式分段。禁止补画缺测峰或把虚拟示例当作材料证据。

## 从 CSV 重绘

用户要求成品可在 Origin 直接打开编辑时，按 [原生 Origin 交付](origin-native.md) 另生成内含数据的 OPJ 和 OGG，数据准备由 Skill 完成。下述 `--mark` 为静态导出的标峰选项；原生图需要的峰位标记在 Origin 中添加并复核。完整仓库的 `examples/spectra/` 包含三种合成图谱，列名为 `x`、`Sample A`、`Sample B`。

脚本支持单横轴、一个或多个 Y 列、空白 Y 保留断点。用 UTF-8 CSV，横轴需严格单调。如果仪器省略了整个已知缺测区间，可在绘图副本中为缺测组加入空 Y 的分隔行，或分别绘制各段。选择图谱类型、列名和已核实的纵轴标签。示例中的 520 是传入的参考位置。

~~~powershell
python scripts/plot_spectra.py --kind raman --csv example.csv --x shift --y Sample-A --y Sample-B --y-label "Intensity (counts)" --mark 520 --output raman.svg
~~~

- `--mark` 可重复传入已知的峰或参考位置。近邻标签冲突时减少标记或改用局部放大。
- `--x-range LOW HIGH` 限定显示范围；`--x-direction` 控制横轴方向；`--x-label` 可指定已确认的其他量或单位。
- `--offset` 设置每组递增的显示偏移，默认为 0。`--profile` 可传本地风格 JSON；检查曲线与背景的对比度。
- 输出 `.png`、`.svg` 或 `.pdf`，可用 `--width-mm`、`--height-mm` 指定成品尺寸。SVG 保留文字。

出图后核对坐标、单位、范围、断线、标签和图例，说明哪些位置是外部标注。对比版本使用同一数据、范围和方向，并记录任何显示变换。对照图、参数和导出物仅用合成数据进入公开包；用户数据、参考卡片与图库留在本地。
